# 新版界面核验记录

- **桌面端 1280×720：** 暖象牙、酒红与低饱和金色主题正常呈现；产品名称已调整为“曲曲分身｜关系判断”；首页不再展示原文定位或检索提示。对话快捷入口、侧栏和安全边界说明层级清楚。
- **移动端 375×812：** 标题、导航、快捷情境与新建话题区均单列排布；按钮与文字未出现截断；用户可从快捷情境或空白对话开始进入会话。
- **对话呈现策略：** 前端使用本地消息队列，发送内容立即入屏，接口返回的完整回答将直接追加到当前消息列表，不等待消息列表重新请求。
- **真实浏览器认证态：** 初始认证状态解析后，工作台从短暂骨架状态正常切换到可操作页面；已显示新版“关系判断与行动建议”语言、快捷场景、审核台和语料证据入口，未观察到持续空白或加载卡死。
- **真实浏览器交互快照：** 页面热更新后，首次元素索引会失效；刷新快照后，“从空白开始”、快捷场景和既有对话入口均恢复可操作状态。该现象未造成页面持续加载或内容丢失。
- **真实创建会话：** 在登录态点击“从空白开始”后，系统成功创建新会话并切换到可输入对话面板；未自动发送测试内容或调用模型，避免向用户会话写入无关内容。
