# 曲曲语气校准

先读仓库根目录的 `AGENTS.md` 与 `CODEX_HANDOFF.md`。本技能服务于曲曲应用，不控制无关对话。

## 使用依据

用户要的是从授权原文保留下来的日常表达和判断推进。原文中的常用词、短句、反问、转折、排比优先于代理改写的抽象术语。区分原文证据、所有者提供的参考答案、所有者纠正和代理推断；不能把后者伪称为曲曲原话或完整思想。

修改生成或重跑时，读取仓库 `shared/voiceDelivery.json` 的最新表达规则。它由本地 Python 与服务端提示词共同读取，不能只改技能而不接入应用。

## 已核准的表达判断

- “别急着找大哥”比“不愿意给恋爱承诺”更符合用户要求的直接口语。前者可以是在排行动顺序，不因未逐字复述“抗拒爱情大哥”就判为理解错误。
- 两份参考的共同推进是：抓住具体条件，尽快给方向，解释得失和原因，交代下一阶段。第一份先提醒，第二份先肯定优势，因此不规定必须先肯定。
- 日常词承担具体判断，反问之后自己回答，排比逐项落到实际事情，建议紧跟原因。不能只堆口头禅、成语或金句，也不能把所有问题写成同样的三条。
- 先校对语料圈内词的角色含义：“爱情大哥”指带恋爱期待给主播刷礼物的观众，不能误读成女主播要当大哥。语气校准不能掩盖人物和否定词理解错误。
- 直接、明确与如实陈述并存。不能用没有依据的绝对化断言制造确定感。

## 回推与修改

从输出回查实际生成路径：是否被固定答案短路、是否混入旧案例事实、原文是否被切得太碎、提示是否强迫每题念同一套账本、抽象总结是否盖过原句、生成上限是否截断解释。只修改已经由实际输出证实的原因。

授权语料及 SQLite 位于仓库之外的私有目录，不得复制进 Git 或发送外部模型。本地生成必须保持离线环境变量。查看相关原文和完整发言段再选词；常见词出现次数不等于特定观点得到原文支持。

保留即时发送和流式输出，不为润色重新引入整段生成后才显示。新人物与新案例不继承旧案例金额和城市；“那礼物收不收”等追问仍承接当前案例。

## 验收

重跑所有者指定的两题：供养上涨且要求停播迁城；漂亮朋友准备做娱乐直播、想挣钱但抗拒爱情大哥。再连续追问一题检查承接。使用应用实际入口生成并记录原始输出，不能用代理手写答案冒充应用结果。

逐项检查：是否回答当前选择、是否使用具体日常词、解释是否推进、动作有无原因、结尾是否交代后续、有无移植旧事实、有无无依据断言。评价真实效果，不能只检查是否包含特定口头禅。明确指出仍未达标的地方。

如果某题由规则固定文本返回，注明它并未经过模型重新生成。需要比较模型表达时，把已核准判断作为约束传给模型；模型不可用时保留兜底，并如实记录路径。
